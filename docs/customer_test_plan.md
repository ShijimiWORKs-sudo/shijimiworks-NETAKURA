# 朝の確認手順

## 1. 起動方法

```bash
cd C:\制作データ\10_App\netazouAI
npm install
npm run dev
```

ブラウザで開くURL:

```text
http://localhost:3000
```

もし `3000` が既に使われている場合は、ターミナルに `http://localhost:3001` のような別URLが表示されます。そのURLを開いてください。今回の確認では別アプリが `3000` を使用していたため、`http://localhost:3001` で動作確認しました。

## 2. 最初に確認すること

- トップ画面が表示されるか
- ヘッダーとヒーローにロゴ画像が表示されるか
- 通常UIにロゴ以外の商品名テキストが表示されていないか
- 新規作成画面に移動できるか

## 3. テスト入力1

```text
毎日投稿したいけど、何を書けばいいか分からない。自分の経験に価値があるのかも分からない。
```

確認項目:

- 発信テーマが出るか
- タイトル案が出るか
- note構成が出るか
- X投稿案が出るか
- Threads投稿案が出るか
- 保存できるか

## 4. テスト入力2

```text
AIを使って副業を始めたいけど、何から始めればいいか分からない。できればお金をかけずに始めたい。
```

ジャンル:

```text
副業
```

確認項目:

- 副業向けのネタになるか
- 実用的なタイトル案が出るか
- SNS投稿に使えそうか

## 5. テスト入力3

```text
映画を見たあとに感想を書きたいけど、いつも「面白かった」だけで終わってしまう。
```

ジャンル:

```text
映画
```

確認項目:

- 映画感想・考察向けの出力になるか
- note記事にできそうな構成が出るか

## 6. 保存確認

- 保存ボタンを押す
- 保存済み一覧を開く
- 保存したネタが表示される
- 詳細画面を開く
- 元メモと生成結果が残っている
- リロードしても残っている

## 7. コピー確認

- X投稿案をコピー
- メモ帳などに貼り付け
- 文章がコピーされている
- Markdownでコピーも試す

## 8. 削除確認

- 保存済み一覧から削除
- 一覧から消える
- リロード後も消えている

## 9. スマホ幅確認

- ブラウザ幅を狭くする
- 入力欄やボタンが大きく崩れないか確認
- 保存済み一覧と詳細画面も確認する

## 10. ユーザーが判断すべきこと

- 生成結果は「使えそう」か
- ロゴのみでブランド表示する方向性は合っているか
- 最初の画面構成で迷わないか
- もっと欲しい出力形式はあるか
- note向けを優先するか、SNS向けを優先するか
- デザインをどの方向に寄せたいか
- 次に本物のAI API連携へ進むか
- 先にUIを整えるか
