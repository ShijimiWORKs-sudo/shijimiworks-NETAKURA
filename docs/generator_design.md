# 疑似AI生成ロジック設計

## 方針

外部AI APIは使わず、入力文から抽出したキーワードとジャンル別テンプレートを組み合わせて生成する。

## 配置

- `src/lib/generator/extractKeywords.ts`
- `src/lib/generator/generateAll.ts`

## 処理の流れ

1. 入力文を句読点、改行、助詞で分割する
2. 短すぎる語、汎用語、ストップワードを除外する
3. 長めの語句をキーワード候補として抽出する
4. ジャンルごとのトーンを選ぶ
5. 発信テーマ、読者の悩み、タイトル、note構成、X投稿、Threads投稿、タグに差し込む

## ジャンル別トーン

- AI: 仕組み化、効率化、自動化、初心者向け、活用法
- 副業: 収益化、小さく始める、継続、失敗回避、実践
- 映画: 感想、考察、視点、作品から得た気づき
- 日記: 個人の気づき、感情の整理、共感
- 仕事: 働き方、悩み、改善、チーム、キャリア
- 生活: 暮らし、習慣、お金、時間、小さな改善
- 創作: 物語、キャラクター、世界観、アイデア、プロット
- その他: 気づき、問題提起、体験談

## 将来差し替え

UIは `generateAll` を呼び出すだけにしているため、この関数をAPIクライアント化すればOpenAI APIなどに差し替えられる。
