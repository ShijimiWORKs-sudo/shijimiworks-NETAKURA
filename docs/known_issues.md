# 既知の問題

- 生成はテンプレートベースの疑似AIであり、本物のAIほど柔軟ではない。
- localStorage保存のため、ブラウザを変えるとデータは共有されない。
- 本番認証、DB、課金、外部連携は未実装。
- コピー機能はブラウザのClipboard APIに依存する。
- `npm audit` で Next.js 経由の PostCSS advisory が中程度として報告される。`npm audit fix --force` は Next 9 への破壊的ダウングレードを提示するため未適用。
- 作業環境では `3000` 番ポートが別アプリで使用中だったため、開発サーバーは `3001` で確認した。
