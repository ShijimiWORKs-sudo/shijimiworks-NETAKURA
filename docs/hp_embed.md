# HP掲載用メモ

## HP掲載用の短い紹介文

思いつきが、投稿の種に変わる。
メモ・日記・映画の感想を、note構成やSNS投稿案に変換する発信支援ツールです。

## HP掲載用の長めの紹介文

メモ、日記、映画の感想、仕事の気づきなどの断片を、発信に使える形へ整理するWebデモツールです。
note記事の構成、X投稿案、Threads投稿案などを作成できます。
現在は開発中のデモ版で、外部AI APIは使用していません。

## ボタン文言案

- 試してみる
- Webデモを開く
- 投稿ネタを作ってみる
- 無料で試す

推奨文言は「試してみる」。
現時点では正式サービスではなく開発中のWebデモ版のため、「無料で使う」よりも試用であることが伝わる表現が適しています。

## リンクHTML

Vercel公開URLが確定したら、`https://YOUR-VERCEL-URL.vercel.app` を実際のURLに差し替えてください。

```html
<a href="https://YOUR-VERCEL-URL.vercel.app" target="_blank" rel="noopener noreferrer">
  試してみる
</a>
```

ボタン風にする場合の例:

```html
<a
  href="https://YOUR-VERCEL-URL.vercel.app"
  target="_blank"
  rel="noopener noreferrer"
  class="demo-button"
>
  試してみる
</a>
```

## 注意書き

現在は開発中のWebデモ版です。
入力内容と生成結果は、お使いのブラウザ内に保存されます。
サーバーには保存されません。
ブラウザのサイトデータを削除すると、保存内容も削除されます。

## iframeではなくリンク推奨である理由

- 入力欄や生成結果の表示領域を確保しやすい
- スマホ表示で高さ不足や二重スクロールが起きにくい
- localStorage保存がブラウザの通常ページとして扱われやすい
- コピー、削除、確認ダイアログなどの操作が安定しやすい
- Vercel側の表示や将来の認証、設定変更に対応しやすい

## スマホ表示時の注意

- HP側のボタンは押しやすいサイズにする
- 外部リンクで開くことが分かる文言にする
- 長い説明文をボタン直前に詰め込みすぎない
- Webデモ側は別タブで開く想定にする
- HP側にiframeで埋め込む場合、画面高不足や二重スクロールが起きやすいため避ける

## 掲載後の確認項目

- HP上のボタンからVercel公開URLへ遷移できる
- 別タブで開く
- `rel="noopener noreferrer"` が付いている
- PCとスマホの両方でボタンが見やすい
- 公開URLでトップページが表示される
- ヘッダーとヒーローにロゴ画像が表示される
- 通常UIにロゴ以外の商品名テキストが表示されない
- 旧名称やカタカナ表記が表示されない
- 新規作成、生成、保存、一覧、詳細、コピー、Markdownコピー、削除が動く
- 注意書きがHP掲載文脈で読める場所にある
