# 要件定義

## アプリ概要

NETAKURAは、ユーザーのメモ・愚痴・思いつき・日記・キーワードを、発信に使えるネタへ変換するAI風Webアプリである。

## 今回のMVP要件

- 外部AI APIなし
- ローカルで動作
- メモ入力
- ジャンル選択
- 出力形式選択
- 疑似AI生成
- 結果保存
- 一覧表示
- 詳細表示
- コピー
- 削除
- 設定画面
- README
- 朝の客先テスト手順書

## 今回やらないこと

- 本番公開
- 認証
- OpenAI API連携
- Stripe課金
- Supabase連携
- Notion連携
- Buffer連携
- 画像生成
- 音声入力
- スマホアプリ化

## 成功条件

- `npm run dev` で起動できる
- ブラウザでトップ画面を開ける
- メモから発信テーマ、タイトル、note構成、X投稿、Threads投稿を生成できる
- 生成結果を保存、再表示、コピー、削除できる
- スマホ幅でも最低限操作できる
