# 画面・コンポーネント設計

## 画面

### ダッシュボード `/`

- アプリ名と説明
- 新規作成への導線
- 保存済みネタ数
- 生成回数
- 最近のネタ一覧
- 設定画面へのリンク

### 新規作成 `/new`

- メモ本文
- ジャンル選択
- 出力形式選択
- 生成ボタン
- 入力クリア
- 生成結果表示
- 保存
- 再生成
- コピー

### 保存済み一覧 `/saved`

- 保存済みネタ一覧
- 検索
- ジャンルフィルター
- 詳細リンク
- 削除
- 空状態表示

### 詳細 `/saved/[id]`

- 元メモ
- 生成結果
- コピー
- 削除
- 一覧へ戻る

### 設定 `/settings`

- ローカルMVP状態
- 外部API未使用
- APIキー不要
- 保存方式
- 将来プラン案
- ポイント消費案
- 将来API差し替え方針

## 主なコンポーネント

- `AppHeader`
- `Card`
- `Button`
- `CopyButton`
- `GeneratedResult`
- `ResultSection`
- `SavedIdeaCard`
- `EmptyState`

## UI方針

白と薄い背景をベースに、操作面はカードで整理する。入力欄は大きく、主要操作ボタンはアイコン付きにする。スマホではナビゲーションとグリッドを1列化する。
