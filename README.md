# NETAKURA

思いつきが、投稿の種に変わる。

メモ・愚痴・日記・映画の感想・仕事の気づきを、note構成・X投稿・Threads投稿に変換する発信支援ツールです。

## 現在の状態

開発中のWebデモ版です。外部有料APIは使用していません。OpenAI APIキー等は不要です。
商品名は `NETAKURA` です。通常のUI上ではロゴ画像のみでブランドを表示し、文字としての商品名は出さない方針です。補足の読み表記やカタカナ表記は使用しません。

入力内容と生成結果は、ブラウザのlocalStorageを優先して保存します。

## 起動方法

```bash
npm install
npm run dev
```

ブラウザで以下を開きます。

```text
http://localhost:3000
```

既に別アプリが `3000` を使っている場合、Next.js が自動で `3001` などを表示します。その場合はターミナルに表示されたURLを開いてください。今回の作業環境では `http://localhost:3001` で確認しました。

## 表記ルール

- 正式名称は `NETAKURA`
- 通常UIではロゴ画像のみでブランド表示する
- ロゴ以外の `NETAKURA` テキストは通常UIに表示しない
- 法務ページ、README、docs、metadata、内部識別子では必要に応じて正式名称を使用する
- カタカナ表記、読み補足、旧名称はユーザー向け画面で使用しない
- 技術的なローカルフォルダ名は既存環境維持のため変更しない
